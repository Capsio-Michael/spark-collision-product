# 接口确认清单 · v0.1 评审稿

日期：2026-10-17（Asia/Shanghai）。配套文档：[接口契约](api-contract.md)。

本清单中的建议是可评审方案，空白不代表接受。每项请填写：**接受／调整／延期，最终决定、确认人、确认时间**。未知负责人、排期保留待指定／待商定。任务范围以当前用户的“伙伴做引擎、自己做交互和接口文档”为依据。

## A. 已由当前用户明确的分工

- 交互方：页面与交互、接口文档编写。
- 引擎方：伙伴负责引擎；引擎交付中是否包含 HTTP 服务、数据库、导出与运行部署，仍需按下表确认。
- 两方共同：数据格式、分析质量样例、联调和验收。
- 人名、GitHub 账号、最终提交人、具体交付时间：待填写，不根据“用户／同事”称谓推断。

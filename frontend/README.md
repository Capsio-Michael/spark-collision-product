# 交互前端 · 首页与材料导入

浅色工作台，暖橙色突出认知变化。开发基准：[接口契约](../docs/api-contract.md)。

## 火花来源与碰撞路径

已在原网站首页与详情集成：橙色单场碰撞、紫色跨场碰撞、灰色待验证线索；支持单场/跨场筛选，以及带来源引用的碰撞路径。点击“查看碰撞路径”直接进入详情对应区域，点击 E 编号核查原文。

示例“先量清等待，再决定优化投入”展示单场碰撞；“自动化的边界，应该由业务风险决定”展示单场起点、跨场细化和新增印证。合成示例不是引擎实际运行结果。多份文件可以同属一场；重复认可不自动升级颜色。旧接口缺少来源信息时显示待补充。

实现：`src/spark-model.js`、`src/spark-view.js`、`src/spark.css`；对接与待确认事项见 [火花来源接口增补](../docs/spark-origins-contract.md)。导入分组与引擎生成仍需双方对接，本次未修改原导入请求。91 项自动检查通过，含 10 项来源语义与兼容检查；浏览器已验证单场/跨场筛选、路径首次定位与原文跳转。

## 本地启动

使用标准浏览器 ES Modules、HTML 与 CSS，没有第三方运行依赖，也不需要构建或安装 npm 包。Node.js 只负责本地静态预览和测试，不是分析引擎。

在 frontend 目录，有 Node.js 时执行：

```sh
npm run dev
```

当前 Windows 环境也可以从仓库根目录执行（脚本自动寻找系统或 Codex 附带的 Node.js）：

```powershell
powershell -ExecutionPolicy Bypass -File .\frontend\start-preview.ps1
```

打开 http://127.0.0.1:5173 。停止服务使用 Ctrl+C；可通过 PORT 环境变量调整端口。预览仅监听本机，不是部署。普通 file:// 打开不支持本页面的模块加载，需使用本地 HTTP 服务。

## 当前能体验什么

- 浅色首页：项目概况、认知变化、关注点、六维视角、待验证问题。
- 关注点文字搜索、“认知变化”“有分歧”筛选。
- 用户项目总览读取引擎当前快照：摘要、覆盖统计、本次判断更新、六个分析视角、验证问题；搜索筛选可用于真实返回数据。
- 判断预览；点击证据，打开真实对应的合成材料段落。
- 查看示例项目或切换到自己的空白项目。
- 粘贴文字、选择／拖放 UTF-8 TXT 与 MD 文件，逐份填写标题、来源、日期、参与者和使用依据。
- 同一批材料可以填写不同信息；复用参与者使用稳定 ID，不按同名自动合并。
- 保存、编辑、移除与恢复本地草稿；未完成的填写自动暂存，关闭和刷新后可以继续。
- 连接本机 v0.1 引擎，独立执行“提交草稿”“开始分析”，按任务阶段轮询。
- 材料区分本地草稿、提交结果待确认、已保存待分析、正在分析、已分析。
- 不完整的分析总览缓存停止展示，保留材料、编辑暂存、项目绑定和待恢复请求；重连后重新读取结果。异常接口数量字段会被拒绝，未知发言人数显示“未知”。
- 查看服务端原文与成功任务的对应版本结果；失败与网络中断保留原数据。
- 窄屏布局、键盘操作、原生模态焦点约束。

首页默认展示的四份材料均为合成案例，engine_mode=mock，不是实时 AI 分析。用户导入的草稿与合成结果隔离；不会用固定案例“分析”用户的材料。草稿保存在当前浏览器 localStorage，清理站点数据会丢失，请自行保留原始文件。

已实现真实接口调用与轮询代码，但**伙伴的真实引擎尚未联调成功**；本机默认地址 127.0.0.1:8000 在材料轮浏览器检查中无法连接。目前已有完整详情、历史对比与 Markdown 导出交互；纠错／候选确认由另一模块并行开发。合成示例与真实引擎结果分别标注，真实接口与模型质量需单独验收。

## 如何接引擎

1. 伙伴按 v0.1 契约启动服务，允许当前页面 origin `http://127.0.0.1:5173` 的 CORS 请求、Content-Type 和 Idempotency-Key 请求头。
2. 点击“连接引擎”，填写本机地址，例如 `http://127.0.0.1:8000/api/v1`，页面先检查 health 与单项目状态，不上传材料。
3. 保存草稿后，选中草稿点“提交草稿”；已提交材料不允许原地编辑或移除。
4. 选中已保存待分析材料，点“开始分析”；完成后打开任务指定快照。无新火花与证据不足同样是合法业务结果。
5. 导入／分析请求结果未确认时，使用页面上的“重试原请求”；它会复用已保存的请求体与幂等 key。不要通过改标题重新导入来处理网络超时。

前端默认仅允许 localhost 或 127.0.0.1 的 HTTP API 地址。已有项目或未确认请求时不允许把本地绑定切到另一服务。暂不支持跨机器访问，后续需要同时调整 URL 校验、CSP 和访问配置。

本地工作区使用 `spark-collision:materials:v2`，首次写入时迁移旧 v1 草稿且不删除旧数据。提交映射、原请求、运行任务及结果缓存都保存在当前浏览器。移除本地草稿可从列表底部恢复；材料编辑器中的“移出本批次”也提供恢复入口。源文件不受影响。

## 代码结构

```text
index.html                 页面入口
src/app.js                 工作台与导入交互
src/styles.css             浅色主题与响应式布局
src/core.js                过滤、转义、草稿校验与本地保存
src/fixtures/demo.js        与契约 Overview 对齐的显式合成数据
src/api/client.js          HTTP 适配层
src/material-editor.js     逐份编辑与本地编辑暂存
src/material-list.js       材料选择、状态和任务展示
src/material-workflow.js   持久化、提交重试、连接与分析任务协调
scripts/dev-server.mjs     无第三方依赖的本地静态服务
tests/core.test.mjs        数据边界、引用及请求契约检查
tests/materials.test.mjs   导入、身份、存储与断网任务恢复测试
```

首页的合成项目与用户项目隔离：前者读取固定案例，后者使用材料工作流中的真实响应。请求重试由工作流保留同一个幂等 key，HTTP 适配层不会静默生成新 key。Markdown 下载由独立的 api/export.js 处理文件响应，不经过 JSON 解析器。

## 认知历史与版本对比

点击侧栏“认知历史”或打开 http://127.0.0.1:5173/#history 。

- 默认比较最新与上一版本；版本、关注点均可切换。
- 默认突出变化字段；可展开未变化内容，或取消勾选查看全部。
- 分开显示判断、条件、事实／观点／推断／假设类型、确认状态、证据、缺口与候选。
- 新关注点显示“此前尚未出现”；首次版本显示“首次记录”，不捏造旧判断。
- 候选始终与当前判断分开，历史页面不发起确认或纠错。
- 原因按区间内每个版本逐次展示；引用使用事件所在版本的证据定位，不混入未来证据。
- “打开该版本完整详情”复用详情模块，传入固定版本与对应数据源。
- 示例历史明确为手工合成，最新 v2 与首页保持一致；用户项目未连接时不显示示例历史冒充真实结果。

历史模块独立文件与协作边界见 [集成说明](../docs/history-integration.md)。历史新增 10 项自动检查，连同现有材料与详情检查共 40 项通过（本轮检查时）。真实历史接口尚未联调。

## Markdown 结果导出

点击页面“导出结果”，选择版本，核对材料范围，点击“下载 Markdown”。从历史页打开时默认选正在查看的较晚版本，导出期间不会自动切换成最新版本。

示例项目支持下载 v1／v2 合成报告，明确标注为手工示例；用户项目从引擎读取指定版本的完整文件。未分析或未连接时说明缺失条件，不用示例替代真实报告。正文包含简报、六个视角、当前与候选判断、碰撞卡、截至本版的判断历史、分歧、验证建议，以及可离线核查的引用出处与段落。未掌握内容如实标缺口。

独立模块与服务协议见 [导出集成说明](../docs/export-integration.md)。导出新增 12 项检查通过，本轮全量 67 项检查通过（包含并行纠错模块）；浏览器实际下载并读取了合成 v1／v2 文件。真实引擎的报告正文与文件接口仍待联调。

## 项目检查后的修复

已补齐用户项目首页，并修复不完整缓存导致启动失败、接口覆盖数量缺少校验／安全展示的问题。新增 `overview-model.js`、`overview-view.js` 与 `overview.css`；详情、历史和纠错仍由各自模块处理。

- 首页显示的是对应快照的维度、变化理由和证据，不使用固定示例补充用户项目。缺失维度、适用条件和证据均明确说明。
- “认知变化”筛选只计本次快照标记的变化；此前某项有突破，不会使后续单纯确认再次算作突破。
- 维度抽屉保留 Finding sections、条件、其他解释及缺口；关联引用读取服务端原文，核对材料、片段和实际引文后高亮。
- 总览缓存结构不完整时只在内存中弃用该缓存，读取时不改写原存储；材料与原请求保留。项目绑定本身损坏时仍停止写入，避免误连另一项目。
- 新增 11 项回归检查，本轮全量 81 项检查通过。隔离合成服务已浏览器检查搜索、筛选、维度／原文跳转、确认后 v3 同步及刷新恢复；没有修改原工作区的材料。仍不代表伙伴真实模型与生产服务已验收。

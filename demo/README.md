# 演示官网与路演材料

本目录是**静态概念演示**。`site/` 展示企业销售、客户服务、制造质量和员工入职四种合成应用场景；其中销售报价案例可交互，使用四份写在 `app.js` 中的合成短记录。点击“加入新对话”改变预设的展示状态，未连接真实分析引擎，也不保存用户输入。页面可在本机离线打开；也可在 `site/` 目录运行 `python3 -m http.server 4173`，再访问 `http://127.0.0.1:4173/`。

销售报价主案例已按 `examples/pricing-boundary/M1.md` 至 `M4.md` 校准原话与人物身份，并与工作台保持同一故事。v1 为 M1 + M2，v2 加入 M3，v3 加入 M4。v3 保存新快照并增加覆盖，判断内容保留 v2，不产生新火花。材料没有记录提问方式，保持“未知”；认可继续验证不等于批准上线。

官网示例也分别展示会议覆盖、重要性演示评分与趋同程度，可展开查看 `demo-0.1` 规则。三阶段的重要性为 4/5、5/5、5/5，不能将新增覆盖或高分解释成结论已验证。

演示顺序：官网首屏介绍产品 → 工作方式 → 四类企业应用场景 → 销售报价交互示例 → 加入第 3 段，看到条件限定与历史 → 点击引文定位原话 → 加入第 4 段，看到“没有新火花”。所有人物、发言和判断均为合成示例，不能当作真实客户证言或已实现功能。

`slides/spark-collision-demo-v2.pptx` 是当前七页路演稿；原六页文件保留供对照，现场请使用 v2。PPT 和官网共用深海蓝、薄荷绿、浅青色视觉体系。第 4 页展示四类企业应用场景，第 5 页详述销售报价案例。PPT 正文为可编辑文字，官网截图嵌入第 6 页。`slides/build_deck.py` 可在本机用 Python 标准库重建 PPTX；`slides/assets/homepage.png` 是新版官网首屏截图。演示前确认 PPT 和网页显示的“概念演示”标签，讲解时明确后端引擎仍在独立开发。

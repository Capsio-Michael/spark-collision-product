# 演示官网与路演材料

本目录是**静态概念演示**。`site/` 内的页面只使用四份写在 `app.js` 中的合成短记录；点击“加入新对话”改变预设的展示状态，未连接真实分析引擎，也不保存用户输入。它可以在本机离线打开；为避免浏览器对本地脚本的限制，也可在 `site/` 目录运行 `python3 -m http.server 4173`，再访问 `http://127.0.0.1:4173/`。

演示顺序：官网首屏介绍产品 → 工作方式 → 体验示例 → 加入第 3 段，看到条件限定与历史 → 点击引文定位原话 → 加入第 4 段，看到“没有新火花”。所有人物、发言和判断均为合成示例，不能当作真实客户证言或已实现功能。

`slides/spark-collision-demo.pptx` 是六页路演稿，和官网共用深海蓝、薄荷绿、浅青色视觉体系。PPT 正文为可编辑文字，官网截图嵌入第 5 页。`slides/build_deck.py` 可在本机用 Python 标准库重建 PPTX；`slides/assets/homepage.png` 是本次定稿的官网首屏截图。演示前确认 PPT 和网页显示的“概念演示”标签，讲解时明确后端引擎仍在独立开发。

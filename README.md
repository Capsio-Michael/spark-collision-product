# 智慧火花碰撞 · 产品定义工作区

状态：**前端与本机模拟服务的主要流程已联调通过**。首页已改为对话式资料入口，拖入文件或粘贴后点击生成，结果先显示卡片、点开再看详情；保留用户项目六维／变化／搜索筛选、材料导入与草稿管理、认知详情、按会议核查原话、独立会议指标、历史版本对比、Markdown 导出和单场／跨场来源展示。已通过实际 HTTP 与浏览器走通 M1～M4 的三版分析、刷新恢复及历史报告下载；模拟服务不调用模型，纠错保存仍返回明确的 501，不能宣称真实 AI 或全部验收项已通过。启动、复跑和已知边界见 [本地模拟联调](docs/mock-integration.md) 与 [前端说明](frontend/README.md)。

## 一句话

把多场会议、访谈与聊天里的智慧火花先在场内标注，再跨场关联同一智慧点的补充、质疑、反例、认同和判断变化，整理成有原话依据、可追溯演变的项目记忆。AI 做深度分析与聚合，用户直接看结果，在使用时纠错；只有关键冲突才请求确认。

## 今天的边界

一个项目；导入 3–5 场合成或明确获准使用的短会议/访谈/聊天文本、Markdown 或粘贴记录；展示会议内和跨会议标注、按会议去重的出现频次、可解释的重要性评分、独立的趋同状态和智慧变化；可从结果点回原话；新增一场讨论后更新认知且保留历史；本地持久化和可读导出。不得使用客户私密材料。无音频转写、OCR、多人权限、企业集成或外部任务自动执行。记忆更新指整理项目数据与判断版本，**不是模型训练**。

## 本机 mock 服务

模拟服务已合入当前交互分支，在仓库根目录运行：

```sh
python3 -m engine.server --port 8000 --db var/spark.db
```

服务只绑定 `127.0.0.1`，地址为 `http://127.0.0.1:8000/api/v1`。默认数据库 `var/spark.db` 在本地持久化并被 Git 忽略；首次演示请使用空数据库。需重演时传入另一个新的 `--db` 路径，避免覆盖现有项目。前端现有 API client 可连接该地址。没有额外 Python 依赖或模型密钥。

```sh
python3 -m unittest discover -s tests -v
python3 tests/http_smoke.py
```

第二条命令要求服务已启动且数据库为空，会导入四份合成材料。代码已经实现单项目、材料导入和原文段落定位、同步完成的分析任务、三版历史、按场次去重的演示重要性评分、Markdown 导出和 SQLite 恢复。`engine_mode` 始终为 `mock`；该引擎只识别冻结案例的精确原话，其余材料不足时明确返回 `insufficient_evidence`。首轮纠错接口返回 `501 NOT_IMPLEMENTED`，不会假装保存成功；真实 AI 分析、正式规则核验和同场多材料分组尚未实现。`meeting_id` 可选，缺省时服务为每份材料单独建场，当前仅适用一场一份材料。

## 工作约定

每个结果都能追到输入片段；材料中的事实、他人观点、AI 推断和已批准行动分开存放与显示。跨会议频次是重要性信号，但不等于意见趋同；未提到某话题不等于不感兴趣，没有依据就可以没有新火花。所有任务须先在协作文档认领，今天优先完成可演示的纵向闭环。
